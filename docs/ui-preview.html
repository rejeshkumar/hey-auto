What Changes in Code
Font
Before: System / Roboto
After: Poppins (free, Google Fonts via expo-font)
Primary Yellow
Before: #FECE26 (pale, low contrast on white)
After: #e47200 (burnt orange-amber — strong, warm, high contrast on white)
Primary CTA button
Before: Yellow button with yellow-on-white label
After: Navy button for primary action — yellow for secondary
Fare Hero (Booking + Ride Request)
Before: Grey #F7F8FA background, black number
After: Full yellow card, fare in bold navy — unmissable
Subscription "Active" card
Before: Pale green pastel (#E8F5EE) — blends in
After: Dark navy gradient card — premium feel, stands out
USP Safety Note
Before: Tiny grey caption text at bottom
After: Green highlighted pill — your strongest selling point
OTP Display (Active Ride)
Before: White card, plain text OTP
After: Dark navy card, giant yellow OTP digits — impossible to miss
Text hierarchy
Before: #1A1A2E text on white (slight navy tint, odd)
After: #0F172A text (true near-black, crisper contrast)
