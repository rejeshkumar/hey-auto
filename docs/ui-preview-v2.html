v1 vs v2 — What Changed
Element
v1 — Light Premium
v2 — Dark / Bold
Background
#FFFFFF — white. Looks like every app.
#0D0D0D — dark. Identity. Orange glows.
Fare number
₹42 in small yellow on grey card. Easy to miss.
₹42 in 60px bold orange on dark slab. Impossible to miss.
Driver Earnings
₹420 in amber on light grey surface. Underwhelming.
₹420 in 26px orange on dark grid. First thing you see.
OTP Display
Navy card, orange digits. Decent but small.
Dark card, 64px orange digits, ambient glow. Unmissable at arm's length.
Primary CTA
Navy button. Generic. Same as 1000 apps.
Full-width orange, shadow glow. It's the only thing to tap.
Accept Ride button
Orange on white. Forgettable. Easy to not tap.
Orange on dark overlay. Glow shadow. Driver taps without thinking.
Map
Green satellite placeholder. Clashes with white sheet.
Dark map (#0a1410). Seamless with dark sheet. Orange auto marker glows.
Subscription card
Navy gradient. Looks out of place on white.
Dark card, orange top border strip, ambient glow. Premium. Consistent.
Font
Poppins. Friendly, warm, rounded.
Inter. Sharp, modern, technical. Tesla uses it. Vercel uses it. Linear uses it.
Card borders
1px #E2E8F0 on white. Multiple nested boxes. Spreadsheet feel.
1px #2a2a2a on dark. Barely visible. Depth through shade, not borders.
